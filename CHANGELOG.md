# Changelog

## 0.3.0

- 与 soloAS 0.3.0 版本同步，扩展功能无变化。
- Synchronized with soloAS 0.3.0; no extension functionality changes.

## 0.2.1

- Support the new CoreExtensions interface and lambda syntax.
- Refresh diagnostics after the type database loads and when a document is reopened.
- Complete and show hover information for Blueprint parent members and interface methods (requires soloAS 0.2.1).
- Stop at breakpoints in lambda callbacks (requires soloAS 0.2.1).

## 0.2.0

- Add interface declarations, inheritance and type checks, and lambda syntax support.
- Publish as the soloAS extension with a distinct identity.
