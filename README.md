# soloAS for Visual Studio Code

基于由 Hazelight 维护的 UE-AS 官方扩展的 fork，为 soloAS 提供 AngelScript 编辑与调试支持。

新增支持接口声明与多接口继承、接口类型检查，以及捕获变量和参数的 lambda 语法（包括委托绑定和排序）。

此版本需要 soloAS 0.3.0。

**请停用原版扩展：同时启用会出现重复诊断。**

[soloAS 网站](https://soloas.cuviss.com)

---

A fork of the official UE-AS extension maintained by Hazelight, providing AngelScript editing and debugging for soloAS.

Adds support for interface declarations, multiple interface inheritance and interface type checks, plus lambda captures and parameters for delegate binding and sorting.

This version requires soloAS 0.3.0.

**Disable the original extension when using this one: enabling both causes duplicate diagnostics.**

[soloAS website](https://soloas.cuviss.com)
